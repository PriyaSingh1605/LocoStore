# 🛒 LocoStore – Empowering Local Shopkeepers

## 📌 About The Project

LocoStore is an E-Commerce platform built to empower local and small shopkeepers by enabling them to sell their products online using a unique Shopkeeper ID.

Our Motto:

> "Any shopkeeper, even a small one, can sell their items online."

LocoStore bridges the gap between local markets and digital customers by providing a secure login/signup system, product management features, and a seamless shopping experience.

How to run-
cd backend 
npm start
cd frontend 
npm run dev

---

## 🚀 Key Features

### 👤 Authentication System
- Customer Signup & Login
- Shopkeeper Signup & Login
- Secure JWT-based Authentication
- Password Hashing using Bcrypt
- Role-based Access (Customer / Shopkeeper)

### 🛍️ Shopkeeper Panel
- Unique Shopkeeper ID
- Add Products
- Edit Products
- Delete Products
- Manage Stock
- View Orders

### 🛒 Customer Features
- Browse Products
- View Product Details
- Add to Cart
- Place Orders
- Order History
